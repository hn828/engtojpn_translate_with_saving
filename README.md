## engtojpn_translate_with_saving
検索欄に英語の文章を入力すると、各単語の訳を表示します。一度に複数の単語の意味を辞書で確認することができます。<br>
単語を保存し、Excelファイルとして取得できます。<br>
以下のURLからアクセスできます。<br>
https://hn828.github.io/engtojpn_translate_with_saving/

<a id="sec1"><h2>基本操作</h2></a>
<strong>1. 翻訳</strong><ul><li>入力欄に単語や文章を入力して下さい。</li><li>Enterを押すと入力欄をリセットし、翻訳履歴を画面下部に押し出します。</li><li>翻訳結果は日本語訳を一部省略しています。元の翻訳結果を確認したい場合は、翻訳結果をクリックするか、右矢印（→）キーを押してください。</li></ul><ul><ul>※注<br>半角スペースを区切りとして単語を認識します。<br>常に入力欄をフォーカスしています。翻訳したい単語や文章を入力する際、<strong>入力欄をクリックする必要はありません。</strong>別のウィンドウで作業を行っていた場合、画面の適当な場所をクリックしてください。<br>辞書データが大きいため、初めに使うときは辞書の読み込みまで数十秒時間がかかることがあります。2回目以降はブラウザのキャッシュを利用するため読み込みが早くなります。<br>翻訳したい文章をコピー＆ペーストして入力する場合、改行は半角スペースと同様に扱われます。<br>大文字と小文字は区別されません。<br>s,ing,edの語尾変化は元の形に戻して検索します。<br>入力がイディオムに一致する場合、イディオムの訳を追加で表示します。イディオムの意味は単語の意味と同様に一部省略しています。詳細は元の日本語訳を確認してください。例)go on</ul></ul>
<strong>2. 保存</strong><ul><li>翻訳結果の<strong>「保存」ボタンを押すと、その単語をお気に入りに保存します。</strong>保存した単語は画面下部に表示されます。</li><li>「×」ボタンを押すと、登録を削除します。「全削除」ボタンを押すと、全ての単語の登録を削除します。</li><li>「自動保存モード：」ボタンを押すか、ShiftキーとEnterキーを同時押しすると、自動保存モードの切り替えができます。<strong>自動保存モードをonにすると、Enterが押されたとき、入力欄の単語の翻訳結果を全て保存します。</strong></li><li>「ラベル：」ボタンを押すと、お気に入り登録する単語に付けるラベルを設定できます。本の名前や講義の名前を設定することを想定しました。ラベルは内部的に記録され、Excelデータで確認できます。</li><li><strong>「Excelファイルを取得」ボタンを押すと、保存した単語の一覧を取得できます。</strong></li></ul><ul><ul>※注<br>既に保存されている語は二重に保存されません。<br>自動保存モードでは訳が見つからない単語は保存されません。内部的に登録回数が加算されます。<br>ラベルの設定は前回の内容を保持しています。<br>「ラベル：なし」に戻したい場合は、ラベルの名称を入力せずにokボタンを押してください。<br>ラベルの設定は任意です。無視しても大丈夫です。<br>Excelファイルには、phrase,short,full,count,labelのデータが含まれます。順に英単語、省略された日本語訳、詳細な日本語訳、保存された回数、ラベルです。<br>お気に入りに保存した単語はlocal strageに保持され、内容を引き継ぎます。</ul></ul>
<strong>3. 使用例</strong><ul><li>英語の本や論文の分からない単語を調べる。</li><ul>履歴が蓄積するため、調べた単語の意味を忘れてしまってもすぐに確認できます。<strong>単語を連続で調べたいときには</strong>、Enterではなく<strong>半角スペースを使う方が簡単で早いです。</strong>自動保存モードをonにして、本の名前でラベルを設定すると、その本で分からなかった単語の一覧を得ることができます。</ul><li>翻訳したい文章をコピー＆ペーストする。</li><ul>入力欄の見た目は1行しかありませんが、入力の長さに制限はありません。改行を含む文も入力できます。</ul><li>Execlファイルを利用する。</li><ul>Excelデータには、count（保存した回数）、labelが含まれます。保存した回数が多い順に並び替えることや、特定のラベルだけを表示することができます。</ul></ul>

<a id="sec2"><h2>ショートカット</h2></a>
Shft+Enter			    ...	自動保存モード切り替え<br>
右矢印（→）キー	    ...	直近の単語の詳細訳を表示。連続で押すと、直近の単語から順に詳細を開く。<br>
下矢印（↓）キー	    ...	全ての単語の詳細訳を表示。<br>
上矢印（↑）キー	    ...	全ての単語の詳細訳を閉じる。<br><br>

<a id="sec3"><h2>不具合</h2></a>
イディオムの訳が表示されない、または、変に表示されることがあります。イディオム検索は元辞書を独自に変換したデータを利用しているため、上手く変換されていないものがあります。元の翻訳を確認してください。<br>ラベルが異なる同じ単語が別々で登録されません。<br>s,ing,edで終わる語に訳が見つからない場合、元の単語が変化して表示されます。

<a id="sec4"><h2>辞書データ</h2></a>
パブリックドメインの英和辞書データEJDictを使用しています。<br><br>
**辞書の記号の意味**<br>
A / B / C	...	列挙。単語にAとBとCの意味があることを示す。<br>
A, B, C	...	Aの言い換えがBやCであることを示す。<br>
A; B	...	異なる意味があることを示す。<br>
A(B)	...	Aの補足Bを示す。<br>
=A / B  ...	Aと同じ意味かつ、別のBの意味も持つことを示す。<br>
〈C〉	...	可算名詞。countableの略。<br>
〈U〉	...	不可算名詞。uncountableの略。<br>
{形}	...	形容詞（adjective）<br>
{副}	...	副詞（adverb）<br>
{動}	...	動詞（verb）<br>
《米》	...	アメリカ英語<br>
《英》	...	イギリス英語<br>
《俗》	...	俗語<br>
《口》	...	口語<br>
《差別的表現》	...	差別的な表現<br>
《まれ》	...	まれに使われる表現<br>
《法》	...	法律用語<br><br>
EJDictについて、詳しくは以下のURLをご確認ください。<br>https://github.com/kujirahand/EJDict<br>https://kujirahand.com/web-tools/EJDictFreeDL.php
