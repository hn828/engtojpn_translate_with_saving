## engtojpn_translate_with_saving
検索欄に英語の文章を入力すると、各単語の訳を表示します。<br>
単語を保存し、Excelファイルとして取得できます。<br>
以下のURLからアクセスできます。<br>
https://hn828.github.io/engtojpn_translate_with_saving/

### 使い方
**1. 翻訳**<br>画面上部入力欄に訳したい単語や文章を入力して下さい。<br>Enterを押すと入力欄をリセットし、翻訳履歴を画面下部に押し出します。<br>翻訳結果は日本語訳を一部省略しています。元の翻訳結果を確認したい場合は、翻訳結果をクリックするか、右矢印キー（→）を押してください。<br><br>※<br>半角スペースを区切りとして単語を認識します。<br>常に入力欄をフォーカスしています。翻訳したい単語や文章を入力する際、入力欄をクリックする必要はありません。別のウィンドウで作業を行っていた場合、画面の適当な場所をクリックしてください。<br>辞書データが大きいため、初めに使うときは読み込みまで数十秒時間がかかることがあります。2回目以降はブラウザのキャッシュを利用するため読み込みが早くなります。<br>翻訳したい文章をコピー＆ペーストして入力する場合、改行は半角スペースと同様に扱われます。<br>s,ing,edの語尾変化は元の形に戻して検索します。<br>元の翻訳結果の文章中に含まれるイディオムと入力が一致する場合、イディオムの訳を追加で表示します。例)go on<br><br>
**2. 保存**<br>翻訳結果の「保存」ボタンを押すと、その単語をお気に入りに保存します。保存した単語は画面下部に表示されます。<br>「×」ボタンを押すと、登録を削除します。「全削除」ボタンを押すと、全ての単語の登録を削除します。<br>自動保存モードをonにすると、Enterが押されたとき、全ての翻訳結果を保存します。「自動保存モード：」ボタンを押すか、ShiftキーとEnterキーを同時押しすると、自動保存モードの切り替えができます。<br>「ラベル：」ボタンを押すと、お気に入り登録する単語に付けるラベルを設定できます。本の名前や講義の名前を設定することを想定しました。ラベルは内部的に記録され、Excelデータで確認できます。<br>「Excelファイルを取得」ボタンを押すと、保存した単語の一覧を取得できます。<br><br>※<br>既に保存されている語は二重に保存されません。<br>自動保存モードでは訳が見つからない単語は保存されません。内部的に登録回数が加算されます。<br>Excelファイルには、phrase,short,full,count,labelのデータが含まれます。順に英単語、省略された日本語訳、詳細な日本語訳、保存された回数、ラベルです。<br>「ラベル：なし」に戻したい場合は、ラベルの名称を入力せずにokボタンを押してください。<br><br>

### 不具合
イディオム検索が変に表示されることがあります。イディオム検索は元辞書を独自に変換したデータを利用しているため、上手く変換されていないものがあります。元の翻訳を確認してください。
