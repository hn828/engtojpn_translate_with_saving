## engtojpn_translate
検索欄に英語の文章を入力すると、各単語の訳を表示します。<br>
### 使い方
**1. 翻訳**<br>画面上部入力欄に訳したい単語や文章を入力して下さい。<br>Enterを押すと入力欄をリセットし、翻訳履歴を画面下部に押し出します。<br>翻訳結果は日本語訳を一部省略しています。元の翻訳結果を確認したい場合は、翻訳結果をクリックするか、右矢印キー（→）を押してください。<br><br> (注)<br>半角スペースを区切りとして単語を認識します。<br>常に入力欄をフォーカスしています。翻訳したい単語や文章を入力する際、入力欄をクリックする必要はありません。別のウィンドウで作業を行っていた場合、画面の適当な場所をクリックしてください。<br>
翻訳したい文章をコピー＆ペーストして入力する場合、改行は半角スペースと同様に扱われます。<br><br>
**2. お気に入り保存**<br>翻訳結果の「保存」ボタンを押すと、その単語をお気に入りに保存します。保存した単語は画面下部に表示されます。<br>「×」ボタンを押すと、登録を削除します。「全削除」ボタンを押すと、全ての単語の登録を削除します。<br>自動保存モードをonにすると、Enterが押されたとき、全ての翻訳結果を保存します。<br>「Excelファイルを取得」<br><br>(注)<br>自動保存モードでは訳が見つからない単語は保存されません。<br>既に保存されている語は二重に保存されません。内部的に登録回数が加算されます。
